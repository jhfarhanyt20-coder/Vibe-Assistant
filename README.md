# Vibe — ভয়েস অ্যাসিস্ট্যান্ট (Android)

Vibe হলো Android-এর জন্য একটা ভয়েস অ্যাসিস্ট্যান্ট। Gemini Live দিয়ে কথা বলে, আর ভয়েস কমান্ডে পুরো ফোন চালায়।

## ডাউনলোড

[Releases](https://github.com/jhfarhanyt20-coder/Vibe-Assistant/releases/latest) থেকে সবচেয়ে নতুন `Vibe-vX.Y.Z.apk` নামাও। প্রথমবার খুললে নিজের Gemini API key চাইবে ([Google AI Studio](https://aistudio.google.com/apikey) থেকে ফ্রিতে পাওয়া যায়)। key শুধু ফোনেই এনক্রিপ্ট করে রাখা হয়।

একবার install করা হয়ে গেলে নতুন ভার্সন নিজে থেকেই আসে। Vibe নিজেই APK টা Download ফোল্ডারে নামিয়ে install-এর স্ক্রিন খুলে দেয়।

## যা যা পারে

- **Live কথোপকথন:** বাংলায় স্বাভাবিকভাবে কথা বলে, মাঝপথে থামানো যায়। ৩০টা কণ্ঠ থেকে বেছে নেওয়া যায় (মেয়ে আর ছেলে)।
- **“হেই Vibe”:** অফলাইনে ডাক শোনে, লক স্ক্রিনেও।
- **Push-to-talk:** চাইলে শুধু বাটন বা ভলিউম-ডাউন চেপে ধরলেই শুনবে।
- **WhatsApp আর voice message:** সরাসরি WhatsApp মেসেজ পাঠায়। Vibe-এর নিজের কণ্ঠে voice message-ও পাঠাতে পারে।
- **স্ক্রিন দেখে নিজেই কাজ:** প্রতিটা ধাপে স্ক্রিনশট দেখে নিজে ট্যাপ আর টাইপ করে। "হয়ে গেছে" বলার আগে স্ক্রিনে মিলিয়ে নেয়।
- **কল আর SMS:** কল করা, কল ধরা বা কাটা, কেটে দিয়ে কলারকে SMS পাঠানো, SMS পাঠানো (আগে পড়ে শুনিয়ে কনফার্ম নেয়)।
- **সব অ্যাপের কন্ট্রোল:** অ্যাপ খোলা, স্ক্রিন পড়া, ট্যাপ আর টাইপ করা, কয়েক ধাপের কাজ, YouTube, অ্যালার্ম, টাইমার, ফ্ল্যাশলাইট, ভলিউম।
- **মেমোরি:** তোমার সম্পর্কে দরকারি কথা মনে রাখে, আর করা কাজ থেকে শেখে। সব ফোনেই থাকে।
- **ভাসমান বাটন:** সব অ্যাপের উপরে থাকে। টেনে ✕-এ ফেললে সরে যায়, কিন্তু Vibe চলতেই থাকে।

## বিল্ড করা

Android Studio (JDK সাথেই থাকে) লাগবে।

```powershell
.\gradlew.bat assembleDebug
```

নতুন ভার্সন প্রকাশ করতে (যেটা install করা সব ফোনে auto-update হয়ে পৌঁছাবে):

```powershell
.\scripts\release.ps1 -Version 0.4.0 -Notes "কী বদলাল"
```

APK সবসময় এই একই PC থেকে বিল্ড করবে। একই signing key না হলে ফোন update নেবে না।
